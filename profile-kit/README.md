# 🎨 Profile Kit — the paste-ready GitHub profile README

Your GitHub profile page currently has **no README** (there's no special
`username/username` repo yet). This kit fixes that in ~3 minutes — and creating
that repo itself counts as a **repository contribution**.

## Setup (3 steps)

1. **Create the magic repo** — name it *exactly* your username:
   👉 <https://github.com/new?name=UCHIHA-MADARA-ANUJ>
   - Public ✔, "Add a README" ✔ → Create.
2. **Open the README for editing** (pencil icon) and paste the entire contents of
   [`profile-README.md`](profile-README.md) from this folder.
3. Commit. Refresh your profile — boom. 💥

Optional but recommended: pin the `Commit` repo (profile → Customize your pins →
select **Commit**) so visitors see CommitQuest right away.
